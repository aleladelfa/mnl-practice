Multinomial logit in R

Ruimtelijke analyse II, practice session 4. R runs inside this page: nothing to install.

Starting R in your browser…






Our question. Which travel mode do older people in Ghent use instead of the car, and which perceptions of their neighbourhood go with that choice?

How to work. Run the steps in order, from 1 to 9. Read the grey tip under each output. Only step 4 needs your own input.




1Load your data


Upload the csv file with your component scores from exercise 1 (it holds all the survey variables plus your components). Then press Run. R reads the file and tells you how many people and variables it holds.
No file uploaded.







If you see cannot open file, you did not upload a file yet. If all columns end up in one column, your file uses a comma between columns: replace read.csv2 by read.csv.






2What do people use most?


Our outcome is the main travel mode. It has four answers: walk, bike, public transport (PT) and car. This is why we need a multinomial logit: more than two answers, with no order between them.







Look at the percentages. The car is the biggest group. We will compare every other mode with the car.






3A table you already understand


Before any model: do people with a De Lijn pass travel differently? Each row adds up to 100%.







Without a pass, about 5% mainly use PT. With a pass, about 30%. A multinomial logit tells the same story in one number per mode, while it holds the other variables constant.






4Name your components (the only block you change)


In exercise 1 your group made its own components. Write your names on the left and the matching column names of your file on the right. The example uses the components of the example file. Add or delete lines so the list matches your group.







Names on the left: no spaces, no accents. Column names on the right: exactly as in your file, between quotes.






5Prepare the data


R copies your components under your names, labels gender, makes the car the reference category, and drops people with a missing answer.







Write down the number of people left. The Ufora test asks for it.






6Fit the model


One line fits the multinomial logit with mnl(), a small function built into this page (in RStudio you would use nnet::multinom(), which gives the same numbers). R estimates three small models at once: walk instead of car, bike instead of car, PT instead of car.







Nothing to read yet. If you see an error that an object is not found, run the steps above first, in order.






7Read the odds ratios


Each cell is an odds ratio: the mode in the column compared with the car, for one point more on the variable in the row.
Above 1: more likely than the car. Below 1: less likely than the car. Stars: the effect is significant (* p < 0.05, ** p < 0.01, *** p < 0.001). No star: we cannot tell it apart from no effect.







Example: passPass under PT is about 9. People with a pass have about nine times the odds of using PT instead of the car. Odds, not probability: do not write "nine times as likely".






8Is the model any good?


Two numbers. McFadden R2 says how much better the model is than a model with no variables. The likelihood-ratio test says whether that improvement is real.







A McFadden R2 of 0.1 to 0.2 is normal for travel behaviour: people choose for many reasons that no survey measures. A p-value below 0.05 for the LR test means the variables together help.






9Write the sentence


Pick one variable and one mode from the table in step 7. Change the two names in the code and press Run. R writes the sentence. Check it against the table, then write it in your own words in the Ufora test.







The template: For [mode] instead of car, one point more on [variable] multiplies the odds by [odds ratio] (p = ...).
